## Key decisions

### briefFmt helper in operations-common.js
`briefFmt(key, n, cls)` — translates an `ops.brief.*` sentence and replaces `{n}` with a
styled `<span class="brief-num {cls}">{n}</span>`. All dashboard narrative blocks use this.

**Why:** Keeps number formatting (colored span) separate from translated sentence text; avoids
scattering `if (lang === 'fr')` in business logic.

### Server brief suppressed from #brief-text
In `renderIntelligence` (director.html), the lines that overwrote `#brief-text` with
`r.executiveBrief`/`r.briefing` were removed. The client-translated narrative now stays.
Server Italian brief is still generated by `ops-intelligence.js`/`ops-assistant.js` — left for I18N-3.

**Why:** Server text is Italian (ops-intelligence.js:691, ops-assistant.js:565). Without a backend
locale refactor it would overwrite the translated client brief. Simple suppression is the minimal fix.

### Language-switch reload hook
Director/CC/Adjoint pages add:
```js
document.addEventListener('click', e => {
  if (e.target && e.target.classList.contains('i18n-lang-btn')) setTimeout(load, 30);
});
```
This re-renders the narrative when user switches language without a page reload.

### Dept card subtitle uses data-i18n attribute
`sub.setAttribute('data-i18n', 'home.openStation')` + `I18n.apply(grid)` after building
the grid. `I18n.apply()` then refreshes it on any future `setLanguage()` call automatically.
