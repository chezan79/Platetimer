## Pattern per page type

### Pages with `type="module"` scripts (home.html, operations-performance.html)
- Add `<script src="js/i18n.js"></script>` + `<script>I18n.init({selector:'#i18n-*-sel'});</script>` as plain scripts **before** the module.
- Inside the module: `const _t = k => window.I18n ? window.I18n.t(k) : k;`
- I18n.init() is async but we don't await it inside the module — it resolves before user interaction and the _t fallback returns the key if not ready yet.

### Pages with plain scripts (admin-departments.html, sala.html, ops-* dashboards)
- Add i18n.js script tag, then call `I18n.init({selector}).then(loadFn)` instead of calling `loadFn()` directly.
- `const _t = k => window.I18n ? window.I18n.t(k) : k;` at top of the script block.

### department.html (pre-existing i18n)
- Was `selector: false` — changed to `selector: '#i18n-dept-sel'` and added `<span id="i18n-dept-sel"></span>` in the header.

## Key gotchas

- **OUTCOME_LABELS / EXC_LABELS in operations-performance.html** are now *functions* (return a fresh object each call) so the labels reflect the active locale at render time, not at module parse time.
- **sala.html** had `window.addEventListener('load', initializePage)` at the bottom — wrapped in `I18n.init({selector}).then(() => { window.addEventListener('load', initializePage); })` so translations are ready before data loads.
- **admin-departments.html** uses `I18n.init({selector}).then(loadAll)` pattern; the synchronous token check at top uses `_t()` safe wrapper that returns the key if I18n is not yet ready.
- sala.* keys were added to all three JSON files for countdown card UI (expired/urgent/active labels, start/duration labels, connection status, voice panel strings).

## What is still NOT translated (server-side, I18N-3 scope)
- Narrative text generated by ops-intelligence.js, ops-assistant.js, ops-trends.js (briefing sentences, workload descriptions).
- System emails via ops-email.js.
- Console/log messages (not user-facing).
